# Reference books

Only this file is published. Every other file in this folder is excluded from git (see `.gitignore`), so the books stay on this computer and are never pushed to the public repo.

## How to add a book
Save a text or EPUB copy (a text-based PDF also works) in this folder. Use the file names below so agents can find them. Agents may convert EPUB or PDF to text with Node when needed.

## Reading list

| File name | Book | Author | Use it for |
|---|---|---|---|
| `little-book-of-valuation` | The Little Book of Valuation: How to Value a Company, Pick a Stock and Profit | Aswath Damodaran | Plain-language valuation; voice and tone |
| `investment-valuation` | Investment Valuation: Tools and Techniques for Determining the Value of Any Asset | Aswath Damodaran | Depth and accuracy on DCF, multiples, cost of capital |
| `narrative-and-numbers` | Narrative and Numbers: The Value of Stories in Business | Aswath Damodaran | Linking stories to numbers |
| `investment-philosophies` | Investment Philosophies: Successful Strategies and the Investors Who Made Them Work | Aswath Damodaran | Investing styles and the people behind them |
| `financial-statements` | Financial Statements: A Step-by-Step Guide to Understanding and Creating Financial Reports | Thomas Ittelson | Teaching P&L, balance sheet, cash flow step by step |
| `financial-intelligence` | Financial Intelligence: A Manager's Guide to Knowing What the Numbers Really Mean | Karen Berman and Joe Knight | Explaining what the numbers mean in everyday language |
